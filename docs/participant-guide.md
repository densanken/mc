# Minecraft サーバー参加案内

参加者へ共有するための案内です。
管理者は、次のプレースホルダーを実際の接続先とバージョンに置き換えてください。

## Minecraft への接続

```txt
接続先: <playit.gg の Minecraft 接続先>
推奨バージョン: <サーバーと同じ Minecraft バージョン>
```

Java Edition から、サーバーと同じバージョンで接続してください。
ViaVersion によって新しいバージョンから接続できる場合もありますが、Minecraft の更新直後は対応していないことがあります。

## Discord アカウントの連携

参加には、Minecraft アカウントと Discord アカウントの連携が必要です。

1. 指定された Discord サーバーへ参加する
2. Minecraft サーバーへ接続する
3. 接続を拒否するメッセージに表示された連携コードを確認する
4. Discord サーバーで `/link` コマンドの `code` に、手順3で確認した連携コードを入力する
5. 連携完了の返信を確認してから、Minecraft サーバーへ接続し直す

## Simple Voice Chat

近接ボイスチャットを使用する場合は、クライアントへ Simple Voice Chat を導入してください。
ボイスチャットは任意のため、導入していないクライアントでもサーバーへ参加できます。
設定画面は初期状態では `V` キーで開きます。

## 夜のスキップ

オンラインのプレイヤーの半数以上がベッドで寝ると、夜をスキップします。
